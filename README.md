# 🏧 ATM Simulator in Python

A simple ATM Simulator project built using Python. This project simulates basic ATM functionalities such as PIN authentication, balance checking, cash deposit, and withdrawal.

## 🚀 Features
- Secure PIN Authentication
- Check Account Balance
- Deposit Money
- Withdraw Money
- Simple CLI Interface
- Input Validation

## 🛠️ Technologies Used
- Python 3

## 📂 Project Structure
```bash
ATM-Simulator/
│── atm_simulator.py
│── README.md
│── requirements.txt
│── LICENSE
```

## ▶️ How to Run

1. Clone the repository:
```bash
git clone <your-repo-link>
```

2. Navigate to the project folder:
```bash
cd ATM-Simulator
```

3. Run the program:
```bash
python atm_simulator.py
```
